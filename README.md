# 移仓助手 · 值守端

期货移仓（换月）机会的自动值守。跑在 GitHub Actions 的机器上，不依赖任何人的电脑，也不依赖沙箱。

## 它做什么

拿当前持仓合约，对后面每一个可交易的远月算「折合每月」：

```
折合每月 = (持仓合约买一 − 远月合约卖一) ÷ 相差月数
```

用**对手价**：卖出近月看买一、买入远月看卖一，已含一次买卖价差。超过设定阈值就推一条到手机（Bark）。

## 值守方式：接力长跑

不指望 GitHub 的 cron 准点——实测它会晚 40 分钟以上，夜盘时段甚至整段不触发（那两小时正好是北美上班时间，全球 CI 都在排队）。

改成一次 job 启动后连续盯 350 分钟，内部每 60 秒检查一轮；收工前用令牌调 API 触发下一次运行，形成接力：

```
06:00 ──睡到 09:00── 09:00 ──── 11:30   上午盘
                        ↓ 睡到 13:00
13:00 ─────────────── 15:00             下午盘
                        ↓ 交棒
15:05 ──── 睡到 21:00 ─ 23:00           夜盘
```

只在盘中干活：09:00-11:30、13:00-15:00、21:00-23:00（按品种看有没有夜盘）。空档期不空转，直接把 runner 让出去等下一跳。

cron 只负责**每天早上把链子拉起来**。启动点定在 UTC 22:00–23:30（北京 06:00–07:30），实测那个时段 GitHub 的调度最准。

## 两个仓库文件

| 文件 | 作用 | 谁写 |
|---|---|---|
| `config.json` | 阈值、持仓、冷却、开关 | 自动（从服务端同步） |
| `state.json` | 上次推送时间，用来算冷却 | 自动（每次推送后更新） |

配置优先级：网页/App 上的设置 > 仓库里的 `config.json`。平时在 App 里改就行，这里不用碰。

## 需要配的 Secrets

| 名称 | 是什么 |
|---|---|
| `BARK_URL` | Bark 推送地址，形如 `https://api.day.app/你的KEY` |
| `SANDBOX_URL` | 配置服务地址 |
| `SANDBOX_KEY` | 配置服务的 sharecode |
| `GH_PAT` | 交棒用的令牌，只需 `Actions: Read and write` |

## 怎么判断它还活着

打开网页看提醒卡片下那行小字：

- 「GitHub 值守中 · 每分钟一轮」→ 正常，网页可以关
- 「本地值守 · 非交易时段待机」→ GitHub 没在跑，或正在等开盘

沙箱只在打开网页看行情时才有用，它休眠不影响推送——推送判断全部在 GitHub 那边完成。

## 两个必须知道的限制

**1. GitHub 的 cron 不保证触发**

官方文档写明高负载时排队的任务会被延迟、极端情况被丢弃。所以这里不靠它准点，只靠它每天成功一次。凌晨那四道冗余（06:00 / 06:30 / 07:00 / 07:30）就是为此准备的——任一次触发，链条就能启动。

**2. 仓库 60 天无提交会被自动停用定时任务**

`watch.js` 里有 `lastKeep` 机制，每 30 天主动碰一次仓库。如果发现推送突然不来了，先看 Actions 是不是被禁用。

## 本地跑一遍

```bash
BARK_URL="https://api.day.app/你的KEY" node watch.js
```

输出最后一行 `RESULT {...}` 就是这一轮的完整结果：查了哪些品种、有几个可换、推没推。

## 品种与收藏

品种表在仓库的 `watch.js` 顶部（`const PRODUCTS`），收录国内六家交易所的全部在交易品种，共 76 个，每个带合约乘数、报价单位、有没有夜盘。

这份表跟网页的 `public/products.js` 是同一份内容——网页那份是权威本，`watch.js` 内嵌的是副本（这个脚本要保持零依赖，Actions 里只 checkout 一个文件也能跑）。**加品种时两处一起改。**

页面上只显示「收藏」的品种，收藏和顺序都存在服务端的 `alert.json` 里（字段 `favorites`），换设备也一样。取消收藏只是首页不显示，`config.json` 里已经设过的阈值会保留，不会顺手把提醒删掉。

品种多不影响每轮耗时：只有「设了阈值 + 有持仓」的品种才会去查行情，而且所有品种的候选合约会合并成一批请求（每 120 个合约一批）一次拉回，不是一品种一发。
